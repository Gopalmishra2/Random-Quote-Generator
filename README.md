# ✨ Random Quote Generator

A simple and responsive web application that displays random inspirational quotes at the click of a button. Built using HTML, CSS, and JavaScript, this project provides users with motivational quotes in an elegant and user-friendly interface.

---

## 🚀 Features

- 📖 Displays random inspirational quotes.
- 🔄 Generate a new quote with one click.
- 🎨 Clean and modern UI.
- 📱 Fully responsive design.
- ⚡ Fast and lightweight.
- 🌐 Runs directly in any web browser.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Gopalmishra2/Random-Quote-Generator.git
```

2. Open the project folder.

3. Double-click `index.html`

**OR**

Run it using **VS Code** with the **Live Server** extension
